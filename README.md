# ComplianceBox

SaaS-платформа для автоматизации соответствия требованиям 152-ФЗ и ФСТЭК для малого и среднего бизнеса.

## 🎯 О проекте

ComplianceBox решает проблему "бумажной безопасности" в МСБ:
- Генерирует пакет юридически корректных документов за 5 минут
- Превращает комплаенс в непрерывный процесс с напоминаниями
- Автоматически обрабатывает отзывы согласий и запросы субъектов ПДн
- Формирует Модель угроз и Проект защиты ИСПДн по методике ФСТЭК

## 📊 Тарифы

- **Free (0 ₽):** 5 базовых документов
- **Start (2 990 ₽/мес):** Обработка отзывов согласий + реестр субъектов
- **Pro (7 990 ₽/мес):** Модель угроз по ФСТЭК 2021
- **Business (14 990 ₽/мес):** Проект защиты ИСПДн + интеграции
- **Enterprise (от 49 990 ₽/мес):** ИСПДн 1-2 класса, SSO, on-premise

## 🏗 Архитектура

- **Backend:** Python + FastAPI
- **Frontend:** Next.js (React) + TypeScript
- **База данных:** PostgreSQL
- **Деплой:** Docker + Docker Compose

```bash

# Запустить все сервисы

open http://localhost:3000
```
